# Instagram Growth Analytics

## Project Overview

This project analyzes 29,999 Instagram posts to identify factors influencing:

- Engagement
- Virality
- Follower Growth

Using Python-based exploratory data analysis and feature engineering, the study evaluates common assumptions about social media performance and growth.

---

## Key Findings

- Content format had less impact than expected.
- High engagement did not necessarily lead to follower growth.
- Excessive hashtag usage reduced performance.
- Traffic source significantly influenced outcomes.
- Virality and growth followed different patterns.
